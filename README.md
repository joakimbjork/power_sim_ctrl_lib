# Power_sim_ctrl_lib
A flexible, MATLAB-based framework for RMS power system simulation with strong support for linear analysis and control design.

## Overview
This platform is a simulation environment designed for efficient and flexible root mean square (RMS) simulation of electrical power systems.
Built on top of MATLAB, the platform enables engineers and researchers to rapidly model, analyze, and design power system dynamics with a focus on:

- Flexibility in system modeling
- Linear analysis capabilities
- Control system design and integration
- Transparent and modular workflows

## Key Features
### Modular & Flexible Architecture

- Easily build and modify power system models
- Supports custom component development
- Designed for scalability from small systems to large interconnected grids

### RMS Simulation

- Efficient simulation of electromechanical dynamics
- Suitable for stability studies, transient analysis, and control validation

### Linear Analysis Integration

- Built-in support for:
-- Small-signal stability analysis
-- Eigenvalue analysis
-- Modal analysis

- Seamless extraction of linearized system models

### Control-Oriented Design

- Strong focus on control theory integration
- Enables:
-- Controller prototyping
-- State-space representation
-- Advanced control strategies

### Use Cases

- Power system stability studies
- Controller design and validation
- Grid integration studies (e.g., renewables, HVDC)
- Academic research in power system dynamics
- Rapid prototyping of control strategies


### Getting Started

Examples:
- CIGRE2024_voltage_and_PODQ_ctrl>main_CIGRE2024
- ISGT2025_partitioned_ctrl>main_ISGT2025

### Philosophy
This platform is built with the belief that:

- Power system simulation should be transparent and customizable
- Linear analysis is essential for deep system understanding
- Control design should be integrated, not an afterthought

### Dependencies
- Matlab 
- Control System Toolbox
